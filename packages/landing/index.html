Three sealed bids. Only the winner is opened.

Each bid on Zcash testnet was a shielded deposit of exactly 0.02 TAZ with a commitment to the bid in its memo. A Groth16 proof shows which commitment holds the highest bid, so the losing bids are never published, not even in the result.

What you still trust

The auctioneer

Sees bids when they are revealed to it and is trusted to settle. Zcash has no contracts, so the rules run in the auction service.

But not blindly

Every input to those rules can be re-read from the chain with the auction's published incoming viewing key.

The setup

The Groth16 setup is single-party. Testnet only, not audited.
